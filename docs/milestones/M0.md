# Milestone 0 — 极小可玩 3D Prototype

- Created: 2026-09-05 · Status: open · Target release: `v0.1`
- charter §4 的完整落地。**M1 不在此规划**——由 M0 retrospective（ISS-010）决定。

## 开工三问（charter §18）

1. **当前游戏真正需要什么？** 一个能"走进去、并且会撒谎"的世界：可移动、有几个房间、房间关系会变一次、玩家能察觉并逃出去。
2. **当前架构能否支持？** 尚无架构——全部临时方案，这正是 M0 的合法状态。
3. **哪里会开始疼？** 见下方「预登记的疼痛点预测」。这些是**预测**，retrospective 时逐条对账：哪条真的疼了、哪条其实没事。

## 验收标准（全部满足即 M0 完成）

1. 按 `docs/build.md` 在 Windows 一次构建成功（单 CMake target）。
2. 第一人称：WASD 移动 + 鼠标视角，不穿墙，帧率在开发机上稳定 60。
3. ≥4 个房间，由门洞连接；**连接关系来自 WorldGraph 数据**，而不是手工摆的墙。
4. 满足触发条件后，世界发生**一次可察觉的变化**（至少一条连接消失或新增），并有 cue（视觉最低要求：颜色/亮度变化；音频不在本期）。
5. 出口在变化前不可达，变化后可达；到达出口有清晰的胜利反馈。
6. 打 tag `v0.1`；Dee 记录 `metrics.snapshot`（event 已定义）。
7. 完成 R-001 retrospective（ISS-010），产出 ≥3 条"压力点 / 仍然够用点"结论。

## Non-goals（本期明确不做）

跳/蹲/vault 等动作；音乐与音频；纹理与光照（扁平颜色即可）；随机生成；存档；菜单/设置；ECS/编辑器/网络（charter §4 全部禁令）；自动化 CI。
